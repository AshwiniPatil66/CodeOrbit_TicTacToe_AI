# Tic-Tac-Toe with Simple AI

## Description

A simple Tic-Tac-Toe game developed using Python.
The player plays against a computer using a rule-based AI.

## Features

- 3x3 Tic-Tac-Toe board
- Player vs Computer
- Win detection
- Draw detection
- Computer tries to win
- Computer blocks the player's winning move
- Handles invalid input

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python tic_tac_toe.py
